# Curso de Inglés A0–B2 — Rubén Muñoz

Proyecto listo para ejecutar con **Vite + React**.

## Requisitos
- Node.js 18+
- npm

## Pasos
1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Ejecutar en local:
   ```bash
   npm run dev
   ```
   Abre el enlace que muestra (p.ej. http://localhost:5173).

## Estructura
- `src/App.jsx`: código de la web (sin shadcn/tailwind para simplificar).
- `public/assets/img/`: tu logo y foto optimizados.
- `public/assets/audio/`: pon aquí los MP3 cuando los tengas.

## Personalización
- Cambia textos, precios y niveles directamente en `src/App.jsx`.
- Sustituye las imágenes en `public/assets/img/` por tus archivos definitivos.
